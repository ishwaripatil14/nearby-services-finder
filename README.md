# nearby-services-finder
# Nearby Services Finder (Full-Stack Geo App)

A complete production-ready full-stack application for finding services like Hospitals, ATMs, and Shops nearby using geographic location.

## Features
- **Interactive Map**: View all services on a map with markers.
- **Radius Search**: Find services within a specific distance (KM) from any coordinates.
- **Category Filtering**: Filter services by type (Hospital, ATM, Shop, etc.).
- **Admin Panel**: Securely manage (Add, Update, Delete) services.
- **PostGIS Power**: High-performance spatial queries using `ST_DWithin` and `ST_Distance`.

---

## Tech Stack
- **Backend**: FastAPI (Python), SQLAlchemy, GeoAlchemy2, PostgreSQL + PostGIS.
- **Frontend**: Next.js, Tailwind CSS, Leaflet (Maps), Axios.
- **Auth**: JWT (JSON Web Tokens).

---

## Prerequisites
1. **Python 3.10+**
2. **Node.js 18+**
3. **PostgreSQL** with **PostGIS** extension installed.

---

## Backend Setup

1. **Navigate to backend folder**:
   ```bash
   cd backend
   ```

2. **Create Virtual Environment**:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

3. **Install Dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

4. **Database Configuration**:
   - Create a database named `nearby_services` in PostgreSQL.
   - Run `CREATE EXTENSION postgis;` in your SQL console.
   - Create a `.env` file in the `backend/` folder:
     ```env
     DATABASE_URL=postgresql://your_user:your_password@localhost:5432/nearby_services
     SECRET_KEY=yoursecretkey
     ```

5. **Run Backend**:
   ```bash
   uvicorn main:app --reload
   ```
   Backend will be at: `http://localhost:8000`
   Swagger UI: `http://localhost:8000/docs`

## Frontend Setup

1. **Navigate to frontend folder**:
   ```bash
   cd frontend
   ```

2. **Install Dependencies**:
   ```bash
   npm install
   ```

3. **Configure API URL**:
   - Create a `.env.local` file:
     ```env
     NEXT_PUBLIC_API_URL=http://localhost:8000
     ```

4. **Run Frontend**:
   ```bash
   npm run dev
   ```
   App will be at: `http://localhost:3000`

## Project Overview (Simple)

This project is a **Nearby Services Finder**.

- Users can view nearby **Hospitals, ATMs, Shops, Others** on an interactive map.
- **Home page**:
  - Shows all services on the map with colored markers by category.
  - Provides a category filter (All / Hospital / ATM / Shop / Others).
- **Nearby page** (Radius Search):
  - Lets you enter Latitude, Longitude and Radius (km) to search services around any location.
  - Lets you choose which category you want to search for.
  - If no services are found, an overlay message appears on the map: *"I can’t search this service. Please try another."*
- **Admin Dashboard**:
  - Allows you to add, edit and delete services.
  - Shows an inline confirmation before deleting: *"Delete this service?  Confirm / Cancel"*

## Quick Run Summary (Backend + Frontend + DB)

1. **Database (PostgreSQL + PostGIS)**
   - Create a database (for example `nearby_services`).
   - In that database, run:
     ```sql
     CREATE EXTENSION IF NOT EXISTS postgis;
     ```
   - In the `backend/.env` file, set your **DATABASE_URL** with the correct user/password.

2. **Backend start (FastAPI)**
   ```bash
   cd backend
   # if the virtual environment already exists:
   ./venv/Scripts/activate        # Windows PowerShell
   uvicorn main:app --reload
   ```
   - Backend URL: `http://localhost:8000`
   - API docs: `http://localhost:8000/docs`

3. **Frontend start (Next.js)**
   ```bash
   cd frontend
   npm install        # first time only
   npm run dev
   ```
   - Frontend URL: `http://localhost:3000`

4. **Login & Test**
   - Admin login: `admin / admin123` (default).
   - Open the Admin Dashboard and add some services with:
     - Name, Category (Hospital / ATM / Shop / Others), Rating, Latitude, Longitude.
   - Open the Home and Nearby pages to test markers, filters and radius search.
